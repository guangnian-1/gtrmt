工作原理（技术说明）

1. 用当前 Token 调官方 getQrcode 铸造并注册二维码（TTL 约 120 秒）
2. 页面根据服务端返回的 timeout 提前自动重新铸造，所以二维码始终有效
3. 微信扫码授权 → 官方回调 → 页面轮询 waitScan 取回 Token（10 分钟）
4. 立即调 /wx/check + agentid=1000031 升级为 4 天长效
5. 长效 Token 继续铸新二维码 → 循环自持，4 天内扫过一次就不会断
6. 扫码时本页被切走也没关系：二维码与 sceneid 会暂存，返回后自动续接取回 Token
